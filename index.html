Section & pattern library 177 blocks

Every pattern has a unique T-number. Tell an AI “use T041” and point it at catalog.json: it maps the ID to a file, anchor, description and set. Each page under pages/ is self-contained HTML you can open locally.

Two switches sit at the top of every page. Theme reskins the whole library, because no block contains a raw colour: they all read the tokens in assets/base.css. Set filters this index down to the core library or the e-commerce blocks.
