Foundations T001–T003

Colour and type foundations: the token palette, the font families, and the type scale behind every pattern.

T001

Colour palette

Every design token as a live swatch, named, with its role and both theme values, so you can see what a block is allowed to use.

This library is token driven. A block must never hardcode a colour: it names a token, and the active theme decides the value. Every chip below is filled with var(--token), so flipping Theme in the toolbar repaints this page live. The pair under each name is what that token resolves to in each theme, read back from the stylesheet rather than typed in.

T002

Font families

The three type roles (display, body, mono) rendered in whichever theme is active, with both themes' families named.

--font-display

Headings

Write it. Burn it. Release it.

Dark: Bai Jamjuree. Moonrite: Fraunces.

--font-body

Body

One card a month, written under the full moon and let go.

Dark: Inter. Moonrite: Instrument Sans.

--font-mono

Code, SKUs and IDs

moonrite-cards-2027

Dark: JetBrains Mono. Moonrite: JetBrains Mono, kept for genuine code only.

Two more tokens pick a face by role: --font-eyebrow for tracked labels and --font-ui for buttons, meta, prices and table headers. Dark points both at the mono face. Moonrite points both at the body face, because a serif page carries its labels in the sans rather than the monospace.
